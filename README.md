# Inversión en salas de oralidad y juzgados

Presentación web interactiva sobre la inversión en infraestructura tecnológica de juzgados y salas de oralidad en Tabasco.

## Uso

La página principal es `index.html`. Para navegar, usa las flechas, desliza horizontalmente o pulsa los lados de la diapositiva. En la diapositiva 3, los nombres de los municipios abren las fichas de juzgados o salas de oralidad. El icono de directorio permite consultar las sedes oficiales y el archivo consolidado.

El proyecto es un sitio estático: conserva todos los archivos de este repositorio juntos y publícalos desde su directorio raíz. Los mapas y el visor de Excel usan servicios externos y requieren conexión a Internet.

La versión publicada en Sitios está disponible en https://presentacion-interactiva-juzgados-tabasco.minjatziri.chatgpt.site/.
